Fast, trap-exact interpreter of make.fun's tiny stack ISA (v1): pre-decoded
dispatch, 32-bit wrapping arithmetic, all ten traps with exact exit codes.
`node /bot/main.ts` answers a whole 40-instance set in ~0.3 s.
Practice score: 1,000,000 / 1,000,000 (40/40 instances, byte-exact).
